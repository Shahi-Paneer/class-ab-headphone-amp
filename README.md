# Class AB Headphone Amplifier

An independent engineering project focused on the design, simulation, prototyping, and implementation of a stereo headphone amplifier using an operational amplifier and a discrete Class AB output stage.

## Overview

The objective of this project is to develop a transparent, low-distortion headphone amplifier while gaining practical experience in analog circuit design, circuit simulation, hardware debugging, PCB development, and electronic instrumentation.

The amplifier will be developed from the schematic level, validated through simulation and breadboard prototyping, and ultimately implemented on a custom printed circuit board.

## Design Objectives

| Parameter | Target |
|---|---|
| Amplifier topology | Op-amp with discrete Class AB output stage |
| Channels | Stereo |
| Supply voltage | ±12 V DC |
| Frequency response | 20 Hz – 20 kHz |
| Maximum output voltage | 5 V RMS |
| Maximum output current | 150 mA RMS |
| Output impedance | < 1 Ω |
| Selectable gain | 1× / 3× |
| THD+N | < 0.01% |

These specifications represent preliminary design targets and are subject to revision throughout development.
